# BDA E-Learning Website

A simple static website for the Big Data Analytics subject. No installation needed.

## Open it
Double-click `index.html`.

## Update content
- **Notes, important questions, documents, notices:**
  upload to Google Drive or type in the Google Sheet. The website updates by itself.
  One-time setup: see `SETUP-GOOGLE.md`.
- **Syllabus, course outcomes, books, evaluation scheme, resources, teacher profiles:** edit `data.js`.
- Local PDFs can go in the `files/` folder, linked as `files/yourfile.pdf`.

## Put it online for free
- GitHub Pages: upload this folder to a repo, then Settings > Pages.
- Netlify Drop (app.netlify.com/drop): drag and drop the folder.
Share the link with students.
